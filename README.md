# أصول للهندسة والتشطيبات

منصة إدارة مشروعات التشطيب والمكتب.

## المرحلة 1 (الحالية)

- لوحة التحكم
- المشاريع + تفاصيل المشروع (تبويبات + معاملات + بنود)
- العملاء
- المقاولون والصنايعية
- الموظفون

## التشغيل

```bash
npm install
npm run dev
```

الواجهة عربية RTL ومطابقة لقطات النظام المرجعي قدر الإمكان.
